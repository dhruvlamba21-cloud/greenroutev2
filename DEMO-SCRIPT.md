# GreenRoute NCR — 3-Minute Demo

1. **Show the planner.** “All the key controls are together: start, destination, travel mode and time of day.”
2. **Choose a sample trip.** Use “Connaught Place → India Gate” or enter another place, then select **Cycle** and press **Compare routes**.
3. **Show the impact gap.** Point to “Cycle vs. drive alone.” Compare estimated CO₂e, travel time and distance for each. Explain that emissions and transit values are illustrative.
4. **Switch modes.** Tap **Metro**, **Bus** and **Solo car**. Point out the colour change: green for active travel, amber for shared transit and red for higher-emission solo driving. The map route changes with the selection.
5. **Show comfort and sharing.** Switch Day / Evening / Night; explain that this provides general guidance, not live street-safety data. Use **Share journey** or **Copy trip summary**.
6. **Close honestly.** “This prototype makes the trade-off easier to see today. Our next step is to add validated local transit and street-infrastructure data.”

## v2 demo tips
- Before presenting: open the site online and run all five example chips once so routes are cached.
- Show the "Time I can spare" slider live: slide it and watch the recommendation change.
- Flip Day -> Evening to show peak traffic hurting the car's time.
- On a phone, mention the haptic feedback and the sticky Share bar.
