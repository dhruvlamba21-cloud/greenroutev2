# Publish GreenRoute NCR

1. Extract `GreenRoute-NCR-One-Screen.zip`.
2. Upload the **contents** to the root of your GitHub repository. `index.html` must be visible at the top level.
3. Open **Settings → Pages → Deploy from a branch**; select `main` and `/(root)`, then save.

No build step, npm install, backend or personal API key is needed. An internet connection is required for the map and public lookup services.
